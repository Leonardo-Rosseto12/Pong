## Sobre o projeto

Projeto desenvolvido em GameMaker utilizando GML, com modos de jogo individual, dois jogadores locais e multiplayer através de uma rede local (LAN).

## Funcionalidades

* Modo individual contra IA.
* Modo para dois jogadores no mesmo computador.
* Multiplayer entre dois computadores via LAN.
* Comunicação TCP/IP entre Host e Cliente.
* Sistema de pontuação e revanche.

## Controles

| Jogador   | Controles |
| --------- | --------- |
| Jogador 1 | W / S     |
| Jogador 2 | ↑ / ↓     |

## Como jogar via LAN

1. Conecte os dois computadores à mesma rede local.
2. Um jogador deve iniciar uma partida como Host.
3. O outro deve selecionar Cliente e informar o IP do Host.
4. Após a conexão, a partida estará pronta para começar.
